# Product Roadmap

## 정책 분류

### 허용

- 수동 또는 예약되지 않은 단일 대상 정보 수집
- 검토된 정적 명령 템플릿
- 사용자가 고른 열거 명령 실행
- 원본 결과 파싱, 검색, 비교 및 시각화
- 사용자가 작성한 HTTP 요청 저장과 반복 전송
- 사용자가 작성·선택한 사실과 증적으로 보고서 구성

### 금지

- 서비스 버전을 근거로 한 자동 취약점 판정
- 익스플로잇 추천, 선택, 다운로드 또는 실행
- 자동 셸 획득과 자동 권한 상승
- 대규모 취약점 스캐닝과 자율 작업 체인
- LLM/AI 분석 또는 공격 계획 생성
- ARP, DNS, NBNS 등의 스푸핑

## Phase 1 — Scan Center

- 스캔 프로필: 빠른 스캔, 전체 TCP, 선택 포트 상세
- 실행 전 명령 검토와 범위 확인
- 실행 큐, 진행 상태, 중단, 재실행
- Nmap XML/일반 출력 원본 보존
- 호스트·포트·서비스·NSE 관찰값 파싱
- 동일 대상 스캔 간 포트 및 배너 변화 비교
- 필터, 정렬, 태그 및 결과 내보내기

현재 구현: 내장 프로필과 안전한 명령 생성, 사용자 범위 확인, 최대 2개 동시 실행,
SSE 실시간 출력, 프로세스 그룹 중단, Nmap `-oA` 산출물 및 SHA-256 보존, XML 자동
파싱, 스캔 간 관찰값 비교까지 연결되어 있다. 애플리케이션 재시작 시 실행 중이던 작업은
`interrupted`로 종료해 실제 상태와 감사 이력이 어긋나지 않게 한다.

완료 조건: 새 스캔과 기존 XML 가져오기가 동일한 Scan/Observation 모델을 사용하고,
중단된 작업도 감사 이력과 부분 출력을 보존한다.

상태: 완료. 대기열·상태 복원, 다중 SSE 구독과 재연결 출력, 산출물 다운로드,
필터·정렬·별칭·태그·CSV/JSON 내보내기, 상세 비교, 대상별 실행 제한, 설정 가능한
전체 동시 실행 수, 출력 스트림 제한, 종료 정리 및 UTC 처리를 구현했다.

## Phase 2 — Service Enumeration

- 서비스·포트별 워크스페이스
- YAML 템플릿 카탈로그와 사용자 즐겨찾기
- 변수 편집, 최종 argv 확인, 실행 및 출력 연결
- 서비스별 체크리스트, 메모, 첨부 파일
- PTY 기반 대화형 명령

완료 조건: 모든 실행이 사용자 확인을 거치고 서비스, 대상, 원본 템플릿 및 결과 파일에
추적 가능하게 연결된다.

상태: 완료. 서비스 메모·태그·실행 이력, 지원 서비스 카탈로그, 저장 출력과 PTY 기반
SSH/FTP/Telnet/smbclient 세션을 구현했다. PTY 입력은 기록하지 않으며 자동 로그인과
자동 셸 획득은 포함하지 않는다.

## Phase 3 — Web Testing Workspace

- 원시 HTTP 요청 편집기
- 메서드, URL, 헤더, 쿠키, 본문 편집
- 사용자가 작성한 요청의 단일·반복 전송
- 응답 상태, 헤더, 본문, 시간과 크기 비교
- 요청 컬렉션과 대상 서비스 연결
- 프록시 설정 및 인증서 검증 선택

자동 페이로드 생성, 취약점 판정, 공격형 퍼징은 포함하지 않는다.

상태: 완료. 사용자 작성 요청, 컬렉션·폴더·태그·변수, 명시적 반복, 프록시/TLS/시간
설정, 요청·응답 이력, 비교용 원본 메타데이터와 바이트 다운로드를 구현했다.

## Phase 4 — Evidence Management

- 파일·스크린샷·텍스트 증적 가져오기
- SHA-256, 취득 시각, 출처 명령, 대상 연결
- `local.txt`/`proof.txt` 메타데이터
- 민감도 표시와 내보내기 전 검토
- 보고서 섹션에 사용자가 증적을 직접 배치

상태: 완료. 출처·해시·민감도·중복 표시, 미리보기, Markdown 메모, ZIP/manifest
내보내기와 보고서 연결을 구현했다.

## Later phases

- AD Information: 사용자 입력 또는 허용된 명령 결과에서 객체·그룹·호스트 정리
- Tunnels and Sessions: 사용자가 만든 터널/PTY 세션 상태, 종료, 감사 기록
- Reporting: 템플릿 기반 Markdown/HTML/PDF 생성과 증적 인덱스

상태: 완료.

- AD Information은 관찰 객체·관계와 CSV/JSON 가져오기만 제공하며 공격 경로를
  계산하지 않는다.
- Tunnels and Sessions는 사용자가 확인한 SSH 포워딩과 PTY 세션의 상태·PID·로그·종료를
  관리하며 자동 피벗을 수행하지 않는다.
- Reporting은 사용자 작성 Markdown, 증적 캡션·인덱스, 민감정보 검토와 HTML/PDF
  내보내기를 제공한다.
- 운영 기능으로 전체 검색, 변경 감사 이력, SQLite 일관 스냅샷과 산출물 ZIP 백업을
  추가했다.
